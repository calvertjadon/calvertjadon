# Jadon Calvert

- [Docu-Kiosk](https://github.com/GTKYCU-IT/docu-kiosk): Containerized Go REST API/WebSocket service, Svelte kiosk UI, and browser extension for member-facing DocuSign sessions.
- [ML implementation experiments](https://github.com/calvertjadon/csc781-ml-showcase): NumPy k-NN and logistic regression compared with scikit-learn, plus PyTorch scratch/pretrained DenseNet-161 experiments on CIFAR-100.
- [NFL play-type classifier](https://github.com/calvertjadon/machine-learning-showcase): pandas/scikit-learn classification with game-context features and random-forest tuning.
